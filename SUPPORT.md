# OpenDeputy Support

OpenDeputy is a community-maintained, pre-release project. Support is best effort and there is no guaranteed response time or service-level agreement.

## Where to ask

- **Reproducible bug:** use the [bug report form](https://github.com/sinabrm/opendeputy/issues/new?template=bug_report.yml).
- **Feature proposal:** use the [feature request form](https://github.com/sinabrm/opendeputy/issues/new?template=feature_request.yml).
- **Setup or usage question:** search the [documentation](docs), [existing issues](https://github.com/sinabrm/opendeputy/issues), and [closed issues](https://github.com/sinabrm/opendeputy/issues?q=is%3Aissue+is%3Aclosed) first. If the answer is still unclear, open a bug report and choose the closest affected area.
- **Security vulnerability:** use the private [security advisory form](https://github.com/sinabrm/opendeputy/security/advisories/new). Never disclose an unpatched vulnerability in a public issue.
- **Community conduct concern:** follow [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).

## Information that helps

Include the OpenDeputy version or commit, Windows version, OpenCode version, affected area, exact reproduction steps, expected result, actual result, and the smallest relevant log excerpt.

Remove provider keys, access tokens, private repository content, personal paths, browser data, and other personal information before posting. Screenshots and logs are public after the repository becomes public.

## Project scope

The supported release target is currently Windows x64. Contributions that improve portability are welcome, but macOS, Linux desktop, mobile, and VS Code packages are not currently shipped or supported by OpenDeputy.
