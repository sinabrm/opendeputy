# Security Policy

## Reporting a vulnerability

Please use GitHub's private [**Report a vulnerability** form](https://github.com/sinabrm/opendeputy/security/advisories/new). Do not open a public issue for an unpatched vulnerability.

Include the affected version, steps to reproduce, expected impact, and any suggested mitigation. Do not include real API keys, access tokens, personal files, or other user data.

Allow the maintainers a reasonable opportunity to investigate and release a fix before publishing details. If you are unsure whether a report is security-sensitive, use the private form.

## Scope

High-priority areas include approval-gated computer/browser actions, terminal and file access, provider credentials, remote access, updates, downloads, Electron IPC, and bundled tools.

## Supported versions

Security fixes target the latest Windows release. There is currently no LTS or backport policy.

Pre-release source builds may change without compatibility guarantees. Check the [Releases page](https://github.com/sinabrm/opendeputy/releases) for the latest published version and checksums.
